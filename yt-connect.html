よくある質問

困ったときは

Q 接続したのにメンバー限定チャンネルがすぐに見えない +
接続が成功してから、メンバー限定チャンネルが表示されるまでに数分〜数十分かかることがあります。少し時間をおいてからDiscordアプリを再起動してみてください。

それでも表示されない場合は、違うGoogleアカウントで接続してしまっている可能性があります。下の項目もチェックしてみてください。
Q YouTubeのアイコンが見つからない +
Discordアプリが古いバージョンだと表示されないことがあります。Discordを最新版にアップデートしてからもう一度やってみてください。
パソコン版の場合は、キーボードの Ctrl + R（Macの場合は Cmd + R）を押すとアプリが更新されます。
Q しばらく待っても限定チャンネルが表示されない +
よくある原因は、YouTubeメンバーシップに加入していないGoogleアカウントでDiscordと接続してしまうケースです。

解決方法: Discordの設定 → 接続 から、YouTubeの接続を一度解除（×ボタン）して、メンバーシップに加入している正しいGoogleアカウントでもう一度接続し直してください。
Q どのGoogleアカウントでメンバーシップに登録したか分からない +
YouTubeアプリを開いて右上のアイコンをタップ → 「購入とメンバーシップ」から、どのアカウントで加入しているか確認できます。
Q 「接続できません」「エラー」と表示される +
ブラウザが新しい画面を開くのをブロックしている（ポップアップブロック）場合に起きます。
解決方法: ブラウザの設定でポップアップを許可するか、別のブラウザ（Chrome、Safariなど）で試してみてください。
Q 今まで見えていたメンバー限定チャンネルが急に見えなくなった +
YouTubeメンバーシップの支払いがうまくいかなかった場合や、メンバーシップを解約した場合に、自動で限定チャンネルから外されます。
YouTubeアプリを開いて、自分のアイコン → 「購入とメンバーシップ」から、メンバーシップの状態を確認してみてください。
