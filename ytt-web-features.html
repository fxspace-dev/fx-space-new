画面は、上から4つのまとまりでできています。

  1. 上：口座と残高
    口座番号の左の丸が緑なら、取引ツールとつながっています。
  2. 右上：「シナリオ」と「成行」
    注文のしかたを切り替えます。
  3. まんなか：チャート
    オートラインや、自分で引いた線が表示されます。
  4. 下：メニュー
    通貨ペア・チャート・ポジション・履歴などの画面に移動します。

PC

PCでは、画面の右側に注文とシナリオがまとまっています。

  1. 右のパネル：口座・残高、ロットの自動計算、成行の注文、シナリオ、シナリオ構築、お気に入り
  2. 上のメニュー：通貨ペアと時間足、スクリーンショット・アラート、ポジション・履歴
  3. 左のツール：チャートに線や図形を引く
  4. 画面のいちばん上と下：ニュースと利確速報、よく見る通貨ペアの切り替え
  5. 右端のアイコン：損益カレンダー・通貨強弱・ヒートマップ・ニュース。いちばん下の歯車が設定
